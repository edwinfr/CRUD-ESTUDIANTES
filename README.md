# Sistema de Estudiantes

Aplicación sencilla en PHP puro, MySQL, Bootstrap, jQuery y AJAX para gestionar estudiantes con operaciones CRUD.

## Requisitos
- PHP 8+
- Servidor MySQL en localhost:3306
- Usuario root sin contraseña

## Ejecutar
1. Asegúrate de que MySQL esté corriendo en el puerto 3306.
2. Levanta el proyecto con:
   ```bash
   php -S 127.0.0.1:8000 -t /home/edwin/Escritorio/web
   ```
3. Abre en el navegador: http://127.0.0.1:8000/

## Funcionalidades
- Registrar, editar y eliminar estudiantes
- Búsqueda por nombre o grado
- Filtros por estado y grado
- Paginación con jQuery y AJAX
